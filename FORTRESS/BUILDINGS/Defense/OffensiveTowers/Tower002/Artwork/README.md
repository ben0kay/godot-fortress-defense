# Tower002 local AA artwork

`aa_base.svg` and `aa_gun.svg` derive from the local Tower001 copies of `ben0kay/godot-tower-defense/TOWERS/Offensive/BattleTower/Artwork/battle_base.svg` and `battle_gun.svg`. AIR2 adds cyan AA chevrons, a winged gun cradle and a blue head tint, keeping64×64 registration and the original muzzle tip. The original Tower001 artwork and reference repository are unchanged. These are repo-local SVG/code assets with no live cross-repository dependency. The base stays stationary; only the gun layer rotates.
